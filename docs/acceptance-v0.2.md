# 《值多少？》V0.2 验收清单

## 产品边界

- 资产只用于建档、估值、统计、变化追踪、人物装备和分享。
- 不提供买入、卖出、兑换、撮合、支付、钱包或订单能力。
- 当前行情来自本地演示数据与用户手动估值，不宣称实时。

## 建议验收路径

1. 首页首屏能看到数字角色、等级、能量、对白和四个资产配件。
2. 点击人物，对白改变、人物轻微跳动、能量增加并持久保存。
3. 点击“开始今日冒险”，领取一次签到能量；当天再次点击不重复领取。
4. 点击“添加资产”，选择分类并创建一条手动估值资产档案。
5. 回到首页，确认总价值、资产构成和角色配件随新档案更新。
6. 在“资产”页点击资产图标，切换“装备中/仅统计”。
7. 在“世界”页切换不同区域，查看区域价值、繁荣度与资产列表。
8. 在“成长”页记录一笔工资或副业收入，调整预测参数并查看未来曲线。
9. 删除一条收入记录，确认只删除统计记录，不影响任何真实资金。
10. 在“我的”页修改角色形象、管理配件和切换名片隐私等级。
11. 分享数字角色名片，确认文案遵循完整金额/区间金额/隐藏金额设置。
12. 关闭并重新打开小程序，确认资产、收入、角色、装备和互动状态仍存在。

## 本地数据

| 数据 | 本地存储键 | 说明 |
|---|---|---|
| 资产档案 | `assets` | 支持新增、更新、归档、恢复 |
| 收入记录 | `incomes` | 支持新增、删除和周期统计 |
| 数字角色 | `character` | 身份与外观 |
| 角色互动 | `interactionState` | 能量、签到、对白和触摸次数 |
| 每日快照 | `dailySnapshots` | 最多保留 365 天 |
| 分享设置 | `shareSettings` | 名片隐私等级 |
