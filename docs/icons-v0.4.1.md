# V0.4.1 像素图标更新

## 范围

- 底部导航：首页小屋、世界地图球、资产宝箱、成长阶梯、个人角色，分别提供灰褐色默认态与彩色选中态。
- 十类资产：房屋、汽车、金融图表、数字金币、笔记本电脑、腕表、会员皇冠、现金袋、猫咪、背包。
- 入口及操作：愿望卷轴、闲置纸箱、收入、晴天/雨天、编辑、能量、归档/恢复、分享、添加、确认。
- 成长路线：幼苗、小船、火箭。

合计35张96×96透明PNG，所有PNG合计约18KB。像素对齐、深色轮廓、奶油高光、森林绿与金币黄统一配色。

图标在 `assets/icons`，矢量源文件在 `assets/icons/source`，生成脚本为 `scripts/build-icons.js`。
生成脚本依赖开发环境的 sharp，仅用于导出；小程序运行不依赖 sharp。
开发脚本、图标源文件、文档和测试已排除在小程序上传包之外，源码交付包保留这些文件。

原有的字符粒子/星光作为动效装饰保留；箭头、金额符号和文字标签不当作图标字体使用。
系统导航栏的标题和返回按钮仍由微信原生提供，不覆盖微信系统控件。

## 验证

- 导航图标必须同时具备默认/选中状态。
- 项目检查验证静态图标路径、十类分类图标和PNG格式尺寸；每张导航图标小于40KB。
- 原有功能测试通过，12个页面模板与14份样式通过微信离线编译器检查。
- 已查看图标总览，确认透明底、图形完整、默认/选中态可区分。
- 本轮未完成手机端视觉复验，未上传微信开发版。
